Employee Management System

A full-stack Employee Management System developed using Java, Spring Boot, MySQL, HTML, CSS, and JavaScript.

Features

- Add new employees
- View all employees
- Search employees by ID
- Update employee details
- Delete employee records
- Filter employees by department
- Dashboard with employee and department counts

Technologies Used

- Backend: Java, Spring Boot
- Database: MySQL
- Frontend: HTML, CSS, JavaScript
- Build Tool: Maven
- Version Control: Git and GitHub

REST API Endpoints

Method| Endpoint| Description
GET| "/api/employees"| View employees
POST| "/api/employees"| Add an employee
PUT| "/api/employees/{id}"| Update an employee
DELETE| "/api/employees/{id}"| Delete an employee

How to Run

1. Install Java 17 or a compatible version required by the project.
2. Install MySQL and create the required database.
3. Configure your database connection in "application.properties".
4. Run the application using Eclipse or Maven.
5. Open "http://localhost:8080" in your browser.
